# Castiglione Conversano

Mini sito statico navigabile sia in locale sia tramite GitHub Pages.

## Uso locale

Aprire direttamente `index.html` nel browser.

## Pubblicazione GitHub Pages

Caricare questa cartella in un repository GitHub e abilitare Pages dalla branch/cartella che contiene `index.html`.

Il sito usa solo percorsi relativi:

- `styles.css`
- `assets/img/...`
- `assets/video/castiglione-web.mp4`

Il video originale non serve per la pubblicazione web; la versione ottimizzata e `assets/video/castiglione-web.mp4`.
